# Char Vowel/Consonant Programı

Bu proje, bir dosyadan karakter okuyan ve her karakterin sesli harf mi yoksa sessiz harf mi olduğunu belirleyen basit bir Java uygulamasıdır.

## Gereksinimler

- Java JDK (versiyon 8 veya üzeri)

## Dosya Yapısı

- `CharVowelConsonant.java`: Ana Java programı.
- `input.txt`: Programın okuyacağı dosya. Bu dosya içerisinde karakterler bulunmalıdır.

## Derleme ve Çalıştırma Talimatları

1. Terminal veya komut satırında proje dizinine gidin.

2. Java dosyasını derleyin:
   ```bash
   javac CharVowelConsonant.java
